## What is Flint?

Flint is a Chrome extension that sits on Claude.ai and scores your prompts in real time. Most people type vague prompts and get mediocre results. Flint fixes that — without you needing to know anything about "prompt engineering."

## How it works

1. **Type a prompt in Claude** — Flint activates automatically
2. **Get an instant score** — 1–10 rating with one plain-English tip
3. **Hit "Improve it"** — Flint rewrites your prompt for you
4. **Get better responses** — aim for 8+ and Claude actually nails it

## Features

- ⚡ Real-time prompt scoring (1–10)
- ✍️ One-click prompt rewrites
- 📊 Usage stats in Chrome's side panel
- 🔒 No account required, no data stored
- 🎯 Built for Claude.ai

## Privacy

Prompt text is sent to our backend for analysis and discarded immediately. We don't store prompts, don't sell data, and don't require an account. See the full [Privacy Policy](https://soohumkaushik.github.io/Flint/privacy.html).
